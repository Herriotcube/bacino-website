Connect your GitHub account

You'll need a personal access token so the editor can save your changes. It only takes a minute to set up, and you only need to do it once.

  1. Ask Herriot to add you as a collaborator on the bacino-website repo if you haven't been already.
  2. Go to github.com/settings/personal-access-tokens/new and sign in.
  3. Under Repository access, choose "Only select repositories" and pick Herriotcube/bacino-website.
  4. Under Permissions → Repository permissions, set Contents to "Read and write" and Pull requests to "Read and write".
  5. Click Generate token, then copy it and paste it below.

Your token is stored only in this browser (never sent anywhere except directly to GitHub) and is only used to save your menu edits.
